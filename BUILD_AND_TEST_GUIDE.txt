TROUBLESHOOTING:

If you don't see Admin button:

  → Check browser console (F12) for errors

If status update shows error:
  → Check that authToken is valid
  → Make sure you're logged in as a user
  → Try refreshing and trying again
  → Check browser console for error details

If database doesn't update:

  → Refresh Neon console to see latest data
  → Check application logs in terminal for errors
