## 🎯 **How to Use:**

### 1. **Login/Register**
```
Go to: http://localhost:8888
Click "Register" → Fill your details → Register
Then Login with your credentials
```

### 2. **View Dashboard**
```
Dashboard shows:
- Active SOS alerts nearby
- Risk zones in your area
- Your current location
- Recent incidents
- Safety tips
- Women resources
```

### 3. **Trigger SOS Alert**
```
Go to: SOS Alert section
Click the large red "🆘 TAP TO TRIGGER SOS" button
Your location is automatically captured
Alert is stored in database
```

### 4. **Track Your Location**
```
Go to: GPS Tracking section
Click "Start Tracking" → Allow location access
Green marker shows your live location on the map
History is shown below with timestamps
```

### 5. **Analyze Risk Zones**
```
Go to: Risk Zones section
Click "Analyze Risks"
Risk zones appear as colored circles on the map
Click circles to see details
```

### 6. **Report Incidents**
```
Go to: Report Incident section
Select incident type (Theft, Assault, etc.)
Set severity level (Low to Critical)
Add description and location
Submit → Data saved to database
```

### 7. **Verify Transport**
```
Go to: Transport Verification
Scan QR code or enter code manually
Get driver details and verification status
Create QR codes if you're a driver
```
